# Sales Performance Dashboard

## Overview
This project analyzes sales data using Power BI to identify trends, top-selling products, regional performance, and business growth insights.

## Tools Used
- Microsoft Excel
- Power BI
- GitHub

## Features
- Monthly Sales Analysis
- Quarterly Sales Trends
- Top-Selling Products
- Region-wise Sales Comparison
- KPI Dashboard

## Files Included
- Sales Dataset
- Power BI Dashboard File
- Dashboard Screenshots
- Project Documentation

## Project Objective
The objective of this project is to transform raw sales data into meaningful business insights using data visualization techniques.
